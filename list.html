중환자실 다중 생체 신호로 패혈증 조기 예측 · 의료진용 대시보드와 위험 알림 설계

중환자실 환자의 다중 생체 신호(PhysioNet 2019 데이터셋)로 패혈증을 조기에 예측하고, 의료진이 한 화면에서 판단할 수 있는 웹 서비스를 기획했습니다. SOFA·qSOFA 점수의 복잡한 계산과 즉시 처치의 어려움을 문제로 정의하고, LSTM·RNN 기반 예측 모델과 서비스 구조를 설계했습니다.

문제
패혈증은 조기 대응이 생존율을 좌우하지만, 기존 점수 체계는 계산이 복잡하고 실시간 대응이 어려움
역할
팀장·PM으로 문제 정의, PEST·STP 분석, 요구사항·기능 정의, 서비스 흐름도와 시스템 아키텍처 설계, 일정 수립
결과물
80% 이상 위험 환자 조회·90% 이상 알림, 환자 상세(실시간 생체신호·환자 일지·랩 데이터 시각화), 모델 인사이트 페이지를 포함한 기획서·개요서
활용·확장중환자실 의료진의 신속한 판단 지원과 의료 자원 배분, 다른 질병 예측 모델·원격 모니터링 플랫폼으로 확장

➜ 이후 같은 팀이 주제를 PPG 기반 비침습 혈당 예측으로 전환해 ‘Cellu’로 구현했습니다.
