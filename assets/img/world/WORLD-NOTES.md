# 한옥 섬 그래픽 수정 · 2026-09-28

플레이 화면은 연결된 WebGL 공간을 유지하면서, 사용자가 승인한 한옥 그림과 어울리도록 개별 미술 자산을 다시 구성했습니다. 전체 배경 한 장을 플레이 화면에 붙이지 않습니다.

- 실제 지형/메시: 강과 굽은 물가, 높이가 있는 절벽, 흙길, 아치형 다리와 난간, 울타리, 흙밭과 디딤돌.
- 개별 이미지 오브젝트: 한옥, 창고, 가로등, 게시판, 우편함, 책상, 벤치, 나무, 꽃, 작물. 승인된 소품과 새로 생성한 식물 자산을 각각 분리하고 깊이 판정을 적용합니다. 고정 시점에 맞춘 2.5D 구현이며 모든 물체가 입체 모델인 것은 아닙니다.
- 지면: 새 잔디 재질과 흙길/흙밭 재질. 넓은 둥근 지형이 강을 덮던 오류를 제거했습니다.
- 동선: 한옥 마당 → 남쪽 작업실 밭 → 새싹 밭, 동쪽 다리 → AI 프로젝트 밭 → 영화관/쉼터.
- 캐릭터 이동, 장애물, 다리 높이와 클릭 경로 탐색은 월드 좌표를 공유합니다. 기존 26개 도착점과 포트폴리오 내용은 유지합니다.
- 캐릭터는 4방향 이미지 애니메이션입니다. 새 달리기는 방향별 8단계, 일정한 축척과 발바닥 기준점, 짧은 체공, 이동 거리 기반 주기를 사용합니다. 관절 리깅 방식은 아닙니다.
